# Questions

One line per question, oldest first. Written at `/cb_ask`, updated at `/cb_close`.

**This is the entry point.** Nobody remembers question ids — they remember "the Avios
thing" or "what Priya asked in March". Search this file and the `aliases:` in each record
before assuming a question is new, and before filing an outcome that arrived weeks later.

A stale index is worse than no index, because people trust it. `/cb_status` repairs it.
